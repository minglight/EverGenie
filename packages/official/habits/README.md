# habits：原子習慣（給秘書看的用法）

習慣是使用者跟某位秘書約的，每個習慣有一個 `agent`（約定的秘書，寫你自己的職位 id）。**點數由套件的程式算，不要自己算、也不要寫 `status` 和 `wallet`。**
所有操作都用 `evergenie data`（種類名稱 `habits.<種類>`）。

## 約定一個習慣
先從很小的開始：兩分鐘內做得完的版本（`two_min`）、綁在一件他已經會做的事後面（`cue`）、一句「我想成為怎樣的人」（`identity`）。再跟他聊清楚：多久做一次（每天或每週幾次）、從哪天開始、要不要自動來源、要不要拆成子項目，並跟他確認連續幾週給一次獎勵（`bonus_weeks`，預設 4；他不要就寫 0；不收 1）。約好之後別隨手改：改了會回頭重算整段歷史，點數又只增不減，改小等於補發點數，要改先跟他說清楚。聊出來的補充寫在內文。

主人會從習慣頁的「約一個新習慣」或「跟秘書討論修改」進來，開頭分別是「我想約一個新習慣：」「我想調整習慣「<名稱>」（H-<n>）：」。頁面只能改名稱、頻率、每週幾次、提示、兩分鐘版本，以及結束或重新開始；其他規則（連漏幾天、一週可休幾天、自動來源、子項目、可漏幾項、連續加分週數）都靠你聊完用 `evergenie data set` 改，改完用一句白話跟他說「怎樣算完成、怎樣拿點」。

```
evergenie data add habits.habit --json '{
  "name": "睡前讀書", "agent": "life",
  "cadence": "daily", "mode": "cumulative",
  "start": "2026-10-26", "status": "active",
  "two_min": "讀一頁", "cue": "刷完牙躺上床之後",
  "identity": "有在讀書的人"
}' --body-file <補充.md>
```
（`agent` 換成你自己的職位 id；每週型改 `"cadence": "weekly"` 並加 `"target": <每週幾次>`。）

- `cadence`：`daily`（每天，`miss_days` 預設 1＝不要連漏兩天）或 `weekly`（要寫 `target`，1–7）。
- `mode`：`cumulative`（達標週數只增不減）或 `streak`（連漏超過 `grace` 週這一輪歸零，賺到的點不收回）。
- `bonus_weeks`：連續達標幾週給一次獎勵點（0–12，沒寫＝4，0＝沒有連續獎勵）。
- `sources`：自動來源，即時推算、不用另外打卡（有裝對應的套件才有用，沒裝就當沒有）：`fitness:重訓`、`fitness:跑步`（或划船、游泳、騎車）、`fitness:有氧`（四種有氧任一）、`fitness:*`、`reminder:R-<n>`。
- `subtasks`：子項目，例如 `["量體重=body:weight", "記錄吃飯=nutrition:meals>=2", "拉筋"]`；當天做到的項數 ≥ 全部 − `allow_miss` 才算當天打卡。
- 改約定：`evergenie data set habits.habit H-<n> --json '{"target":4}'`；結束：`{"status":"ended","ended":"<日期>"}`，重新開始：`{"status":"active"}`（`ended` 不拿掉也沒關係，狀態是 `active` 時不看它）。

## 打卡與撤銷
```
evergenie data add habits.checkin --json '{"habit":"H-3","date":"2026-10-26","source":"manual","key":"manual:H-3:2026-10-26:"}'
# 有子項目：加 "sub":"拉筋"，key 最後面也放子項目名稱
# 撤銷（取消同一天最後一筆還有效的打卡）：
evergenie data add habits.checkin --json '{"habit":"H-3","date":"2026-10-26","source":"manual","undo":true}'
```
看板「今天」卡的「今天不做」只把卡片收到明天（記在那台瀏覽器），不寫任何紀錄；不用、也不要替它補打卡或跳過。
同一個 `key` 只算一次。不能打未來的卡（未來日期的打卡不會被算）。

## 看狀態
```
evergenie data get habits.status h-3      # 本週進度、連續週數、離下一點還差幾週、最近 8 週
evergenie data get habits.wallet main     # 錢包：賺到、花掉、可以用的點數、現在換不換得到衣服（outfits_ready）
```
打卡後約 2 秒程式才算完。點數有兩種，加起來就是這個習慣的點數（`earned_points`），只增不減；賺到新的點數時，程式會通知使用者（通知上有按鈕：點數換得到衣服時「到展示間」，在那裡換角色的衣服；衣櫃沒開、或還沒有要點數的衣服時「到習慣頁」，也不說換衣服）。
- 累積：第一次累積 2 週達標 +1 點，之後每累積 4 週 +1 點（`next_need_weeks`）。
- 連續獎勵：連續週數（`streak_weeks`）是一週接一週都達標的週數，**漏一週就歸零**（`grace` 不影響它）；週中才約定的那週（skip）和還沒過完的這週（open）不加也不斷。每連續達標 `bonus_weeks` 週（預設 4：第 4、8、12… 週）再 +1 點（`bonus_points`，離下一次還差 `next_bonus_weeks` 週）；斷了重來，已經給的獎勵不收回。

- 起手禮：家裡第一個習慣約好，程式另外送 1 點（每個家只一次；結束、刪掉再約都不再送，起手禮上線前就有過習慣的家不補送）。錢包的 `starter` 是 `given` 就是送過了、`starter_habit` 記送給哪個習慣；也會通知使用者一次。
- 跟主人說話時只有一種「點數」（錢包裡、換衣服用的）：待辦做完攢的（`task_points`）畫面上叫「累積」——「問我做了沒」「秘書幫我確認」的待辦做完，簡單 1、普通 2、困難 3，過期每滿一週再 +1；累積滿 30 在待辦頁按「換成 1 點」。不要說「待辦點數」「做完 30 件」。
- 錢包的 `earned`＝全部習慣的點數＋待辦累積換到的＋起手禮；`spent` 是在展示間換衣服花掉的；`points` 是還能用的。
- 錢包的 `outfits_ready`：點數現在換不換得到衣服（衣櫃在用、而且有上架要點數的衣服）。跟主人說點數時照它：是 true 才說可以到展示間換衣服；不是就說點數先存著、之後有衣服可以換時用得到。

## 第一次介紹
新家還沒有人介紹過習慣時，每位秘書的指令裡會多一段「第一次介紹」，照那段做：主人本人跟你說話時先照常回，再寫一筆 `evergenie data add habits.welcome --id main --json '{"status":"done","agent":"<你的職位 id>"}'`，**寫成功才**用你自己的口吻補一兩句（可以跟你約一個很小的習慣、約好送 1 點、做到有點數換衣服）；寫不成（已經有資料＝別的秘書講過）就什麼都不提。只講一次，他沒接話也不再提。之後不要自己寫或改這筆；升級前就在用的家，程式會寫 `skipped`，不用介紹。

## 原子習慣四原則
約定和聊習慣都照這四條：很小（兩分鐘內做得完）、很明顯（綁在一件已經會做的事後面，寫進 `cue`、`two_min`）、不連兩次漏（連跳一天不算斷，連兩天才斷；一週最多跳 `week_skips` 天，預設 2）、不念（沒做不催、不講道理）。

## 不念不催
- 主人沒做到：不提醒、不責備、不主動問進度；他自己提起時再聊，問他要不要把版本改小或換個提示。
- 賺到點、起手禮的通知由程式發，你不用另外再說一次。
- 戒掉壞習慣、回頭看做得怎樣：沒有專門的頁面或資料，主人提起時用聊的帶（例如把壞習慣的提示藏起來、讓它變麻煩；回顧就一起看 `habits.status`）。
