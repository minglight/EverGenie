# 費用與帳號

主人問「要不要錢」「為什麼不回了」「怎麼又要登入」時，照這份回答。跟主人說話用白話，不丟指令給他。
**不要說出金額或方案名稱**：那是 Claude 那邊訂的、會變。主人問多少錢，請他到 Claude 官網看目前的方案。

## 要不要錢

- EverGenie 本身免費。
- 秘書用的是主人自己的 Claude 帳號：要有一個 **Claude Code 能用的 Claude 訂閱**。這筆錢是付給 Claude 的，不是付給 EverGenie；EverGenie 不經手、也看不到付款資料。
- 秘書用得越多，訂閱的用量就用得越快。看板「設定 → 這台電腦」有量到用量時會顯示用了多少。

## 額度用完

- 看板寫「額度用完，幾點恢復」：這是 Claude 訂閱的用量上限，不是壞掉。
- 時間到會自己恢復，排著的話會自己補送。不用重開、不用重送、也不用找誰修。
- 想知道幾點恢復：`evergenie quota`（有量到才看得到）。
- 常常用完：請主人到 Claude 官網看目前的方案有沒有用量比較多的；要不要換由他決定。也可以把不急的事排到離峰（例如夜班）。

## 要重新登入

主人會收到通知「AI 帳號要重新登入」。這只有主人自己能做（要用他的帳號在瀏覽器登入），秘書不代他登入、不碰帳密。做法：

1. 到裝 EverGenie 的那台 Mac 前面。
2. 按 ⌘＋空白鍵，搜尋「evergenie 修復」，打開它（它在「應用程式」資料夾，安裝時放的）。
3. 它會先檢查一遍，然後問要不要重新登入 AI 帳號；照畫面選。
4. 瀏覽器會自己打開 Claude 的登入頁，照畫面登入；登入好那個視窗會自己繼續，不用打任何字。
5. 登入好，回看板再說一次話，就會接著做。那則通知會自己收掉。

登入好之前，用這個帳號的秘書都沒辦法做事；這時候她們也收不到話，所以平常就可以先讓主人知道有「evergenie 修復」這個東西。

## 帳單或方案有問題

主人會收到通知「AI 帳號的帳單或方案有問題」。多半是付款沒過或訂閱到期。做法：用瀏覽器登入 Claude 官網，到帳號設定裡訂閱與付款的地方處理；處理好回看板再說一次話就會接著做。秘書幫不上付款的忙，只能陪他看畫面上寫什麼。

## 不只一個帳號

看板「設定 → AI 帳號」可以再加帳號，指定哪位秘書用哪一個。每個帳號各自要有自己的 Claude 訂閱、各自登入。一個帳號額度用完時，可以把秘書換到另一個帳號。

## 隱私

- 主人跟秘書的對話會送到 Claude 處理（這是秘書能回話的方式），照主人自己那個 Claude 帳號的條款。
- EverGenie 不會自己把任何東西送給提供程式的人。「回報問題」（看板「設定 → 系統健康」）只整理內容給主人看，要不要傳出去由他決定；內容不含對話、帳號、電腦名字。
