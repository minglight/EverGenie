# 夜班：每週額度重置前最後兩晚，把「反正會重置掉」的額度用在主人排好的事上

Status: DRAFT — P6-6（2026-10-26），pending author review.

這份是 `system` 的夜班排程（使用者的資料，不是核心內建的樣板）要照著做的規則；搬家當天用它替換舊家 `features/system/jobs/night-shift.md` 的內文。核心不內建夜班排程，也不在這一步改任何家的排程。

排程預設每週一、週二 00:05，對應「帳號每週額度重置前最後兩晚」；主人的帳號重置時間不一樣，就請他讓你改這個排程的時間（`evergenie jobs set`）。
不用主人半夜起床；只做他預先放進夜班清單的事，沒有就不做。

夜班清單是 vault 的一則筆記（編號 `system/night-queue`，在看板「設定→電腦→夜班清單」看與改，格式見 `schemas/memory.md`）。用 `evergenie night …` 讀寫，不要自己改檔案。

## 開工前（任一不符就收工：日誌寫一行原因，不推播、不開單）
1. `evergenie night list` 看「待做」。是空的 → 日誌寫「夜班清單是空的」，收工（不燒額度）。
2. 看用量：`evergenie quota check --5h-max 80 --week-max 85 --reset-within 30`
   - 結束碼 0：繼續。
   - 結束碼 3（距每週重置不在 30 小時內）：重置時間跟排程對不上。**不要做夜班**；開確認：
     `evergenie reminders add --follow confirm --owner system --at "<現在>" --source routine:night-shift --content "夜班沒跑：每週重置時間跟排程對不上（<quota 印的那行>），要改排程嗎？"`（安靜時段會自動延到早上）。
   - 結束碼 1（用量已超過上限）或 2（沒有資料）：收工，日誌寫 quota 印的那行。
3. 判斷是第幾晚：今天是週一（第一個夜班）是**第一晚**，主人白天還要用，留一點（每週上限 85%）；
   週二是**最後一晚**，剩下的反正會重置，可以放寬（每週上限 97%，留一點給各位的夜間整理）。

## 一項一項做（由上往下）
- 每一項開始前先跑 `evergenie quota check --5h-max 80 --week-max <85 或 97> --reset-within 30`，結束碼不是 0 就停。5 小時上限 80%：要留空間給清晨各位的夜間整理。
- **現在時間 ≥ 03:30 不開新項目**，進行中的收尾：03:45 的夜間整理（`nightly`）要輪替這個 session，被擋住會整晚沒整理。
- 一項只做 30 分鐘內有成果的部分；沒做完的，進度寫在那一項底下（縮排的一行），留給下一晚。
- 做不了的（要 sudo／密碼、要主人決定、花點數或錢、對外寫入：push、改公司系統、寄信、新權限彈窗）：不做，用 `evergenie night block <n> --reason "<一句原因與他要做什麼>"` 移到「要主人」。不要卡在權限彈窗上等人。
- 專業屬於別位的事，可以用 Agent 工具借她的專業（`life`、`work`…）；不要用 `evergenie say` 吵醒她們的常駐 session。
- 做完：`evergenie night done <n> --result "<一句結果與產出位置>"`（會移到「做完」，順便清掉做完超過 14 天的）。序號是「待做」由上往下的序號，**每做完或卡住一項，後面的序號都會往前**，所以每次先 `night list` 再動手，並在 `done`／`block` 加 `--expect "<那一項文字的開頭>"`：序號跑掉時會拒絕、不改錯項目。

## 收工
- 日誌一行：`- HH:MM 夜班（第一晚／最後一晚）：做了哪幾項`（加上 5 小時 N%、每週 N%）。
- 有項目進了「要主人」→ 開一則確認讓他早上看：`evergenie reminders add --follow confirm --owner system --at "<現在>" --source routine:night-shift --content "夜班有 N 項要你決定：見看板「設定→電腦→夜班清單」的「要主人」"`。
- 其他都不推播（安靜時段）。

## 邊界
- 只做清單上的事；不自己加項目、不改別人的設定、不重啟別位的 session。
- 不讀 token、不印 token。花錢或點數的事一律不做。
- 清單裡的「主人」就是使用者本人；寫進清單、日誌、確認的文字一律用「主人」，不寫人名。
