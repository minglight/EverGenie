# 說話測試的預設情境

沒有 `personas/_test/scenarios.md` 時用這一份。想換成自己的情境，在家裡建那個檔案（格式一樣）。
- 標題格式：`## <id>｜<標題>[｜職位,職位]`。沒寫職位＝每個座位都跑；同一個 id 可以依座位寫不同版本。
- 每一段的內文就是主人這一輪送進去的訊息；`{name}` 會換成被測人設的名字。
- 測試不開工具；要模擬「已經做完事」的情境，把事實寫在 `[實驗模擬]` 裡。
- 梗本（全家共用的老梗）：`[梗本] <認得出這條梗的字>/<別的說法>｜<那一行梗>` 換掉這則開場的梗本（只用情境寫的，不看家裡的）；`[檢查] 提梗 <條數>` 或 `[檢查] 提梗 <最少>-<最多>` 跑完照回覆自動判：回覆裡出現幾條梗的字（同一條提好幾次算一條），不在範圍就標 ✗。這兩種行不會送給秘書。

## report｜長回報
[實驗模擬] 你剛幫主人做完一件事。以下是你查到、做完的事實，用它寫回報，不要再用工具：
- 主人交代：把「家事清單」專案的備份流程整理好。
- 完成：寫了 3 份說明文件、修好 2 個設定錯誤，跑過一次完整備份，都成功。
- 順手發現：舊的備份資料夾佔了 12 GB，還沒清；要不要清得由主人決定。
- 還沒做：雲端同步的部分，要等主人給帳號資訊。
- 全部花了約 40 分鐘。
現在寫給主人的最後回報（他會在手機看板上看）。
